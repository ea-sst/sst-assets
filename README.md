# Supply Steer public assets

Images referenced by outgoing email. Public on purpose: a mail client has to be
able to fetch them without signing in.

An image embedded inside a message instead would show as an attachment in
Gmail, with a paperclip and a file strip under the subject. Loading from a URL
means the message carries no image parts at all, so there is nothing to list.

| File | Used by |
|---|---|
| `eisa-signature-round-v10.png` | the email signature, in `operations/tools/email_style.py` |

Nothing private belongs here.
